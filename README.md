# 北京时间翻页时钟

纯黑背景、六张独立的机械翻页卡片，显示 24 小时制的北京时间 `HH : MM : SS`。页面没有按钮、标题、日期或其他可见文字。

在线使用：**[打开翻页时钟](https://2461811168qqcom-ui.github.io/flip-clock/)**。

源代码：[GitHub 仓库](https://github.com/2461811168qqcom-ui/flip-clock)。已部署到 GitHub Pages，可在平板浏览器中打开并添加到主屏幕。

## 打开使用

直接双击 `index.html`，或将其拖入 Edge、Chrome、Firefox、Safari 等现代浏览器。三个网页文件需要保存在同一个文件夹。无需安装软件、构建项目、启动服务器或连接网络。

Windows 浏览器按 **F11** 进入/退出全屏；macOS 可以使用浏览器的全屏快捷键 **Control + Command + F**。支持 Fullscreen API 的平板浏览器中，双点时钟进入/退出全屏，没有额外按钮。

## 平板主屏幕应用（PWA）

在线版本必须通过 HTTPS 访问。首次联网打开后停留几秒，等 service worker 将全部应用资源缓存完成，再添加到主屏幕。

- **iPad**：Safari 打开网址 → 分享 → 添加到主屏幕 → 如果出现“作为网页 App 打开”，保持开启 → 添加。以后从主屏幕图标打开；地址栏不会出现在独立应用窗口中。
- **Android 平板**：Chrome 打开网址 → 右上角菜单 → 安装应用或添加到主屏幕 → 安装。以后从主屏幕图标启动。
- manifest 优先请求全屏、横屏；不支持全屏模式时浏览器可回退到独立窗口。iPad 等平台可能仍保留系统状态栏，横屏锁定也由平台决定；请手动将设备横放，并关闭竖屏方向锁定。
- 支持 Fullscreen API 时双点时钟切换全屏；不支持该 API 时使用主屏幕应用模式。
- 联网缓存完成后，临时断网、关闭应用后断网重新打开、断网刷新都可显示实时北京时间和翻页动画。删除网站数据、清理系统缓存或浏览器自动回收存储后，需要重新联网缓存。
- 支持 Screen Wake Lock API 且浏览器允许时，前台自动申请保持亮屏；切换回前台时重新申请。不支持或被省电策略拒绝时，请调整平板自动锁屏设置。

本地双击打开仍可使用时钟，但 `file://` 不支持 PWA service worker 安装；安装和离线缓存应在在线 HTTPS 地址完成。

## 项目文件

- `index.html`：页面结构与复用数字卡片模板。
- `style.css`：纯黑白响应式布局、上下半片与 3D 翻页动画。
- `script.js`：北京时间读取、独立数字更新、秒边界调度与后台恢复。
- `pwa.js`：离线缓存注册、双点全屏和前台保持亮屏。
- `manifest.json`：应用身份、相对路径启动地址、全屏和横屏偏好。
- `sw.js`：版本化应用资源缓存，兼容 GitHub Pages 项目子路径。
- `icons/`：192px、512px、maskable 512px、Apple 180px 本地 PNG 图标。
- `.nojekyll`：GitHub Pages 原样发布静态文件。
- `README.md`：运行方式和实现说明。

## 时间与动画

使用系统当前绝对时间 `new Date()`，交给 `Intl.DateTimeFormat`，明确指定 `timeZone: "Asia/Shanghai"`、`hour12: false`，并使用拉丁数字和两位补零。午夜小时额外规范到 `00`，不依赖操作系统的本地时区。

每次刷新重新读取真实时间，并用 `setTimeout` 对齐下一秒的边界，不累加秒数。后台暂停刷新；返回前台、窗口重新获得焦点、页面恢复时立即校正。跨越较长时间时直接同步到最新时间，避免播放过期动画。

每张卡片只在数字发生变化时翻动：旧上半片从 `0°` 折向 `-90°`，新下半片从 `90°` 展开到 `0°`，总共约 **640ms**。使用 `perspective`、`rotateX`、`transform-origin` 与 `backface-visibility`，上下半片共享相同的数字排版以避免错位。用户启用系统“减少动态效果”时缩短动画。

系统时间本身必须准确；此离线网页不会联网校准电脑的系统时钟。修改系统时区不影响北京时间，修改系统绝对时间则会影响显示。保持操作系统自动校时即可。

尺寸由视口宽高共同约束，适配笔记本、1920×1080、2560×1440、3840×2160，以及竖屏小尺寸设备；页面禁止滚动。

平板版按可用视口放大，在保持原有卡片比例、字体和间距的前提下，横屏时整体时钟宽度超过屏幕宽度的 95%。支持动态视口高度与设备安全区域，地址栏收起、旋转设备或进入全屏后自动适配。

## GitHub Pages 部署

将此文件夹内的文件和 `icons/` 目录放到仓库根目录。GitHub 仓库 → Settings → Pages → Source 选择 Deploy from a branch → Branch 选择 main → 文件夹选择 / (root) → Save。

所有应用链接、图标、service worker 与缓存 URL 使用相对路径，适用于 `https://账号.github.io/flip-clock/` 这类项目地址，无需手动修改路径。默认没有额外框架、构建或外部 CDN。

更新应用文件时，同时增加 `sw.js` 的 `VERSION`，例如从 `v1` 改为 `v2`。新版本资源全部下载成功后才激活；只清理当前应用作用域的旧缓存，不清理同域其他网页缓存。

- 每秒自动翻页；只更新变化的数字，保留原有六张卡片 DOM。
- `23:08:59 → 23:09:00`、`12:59:59 → 13:00:00`、`23:59:59 → 00:00:00`。
- 验证两个动画阶段都产生真实的 CSS 3D 旋转矩阵，结束后数字一致且动画状态清理完成。
- 模拟延迟刷新、后台挂起十小时后恢复、系统时间回拨，均正确同步。
- 检查 1920×1080、2560×1440、3840×2160、1366×768、1280×800、375×812、320×568、812×375：时钟居中、纯黑背景、无页面溢出。
- “减少动态效果”模式正常结束；浏览器未出现 JavaScript 异常。
- 新增平板尺寸 1280×720、1920×1200、1024×768、1180×820、1366×1024 和 800×1280 检查。横屏整体宽度超过视口 95%，无滚动条。
- manifest 在实际浏览器中解析无错误，图标与全屏/横屏配置完整。
- 在 `/flip-clock/` 模拟 GitHub Pages 子路径，service worker 正确注册、激活、控制页面，十项应用资源完成预缓存。
- 实际禁用浏览器网络后刷新网页，页面与每秒翻页继续运行；断网加载图标、通过带查询参数的 `index.html` 启动均通过。
- Chromium 的 PWA 可安装性检查无错误；真实输入手势双点时钟，Fullscreen API 成功进入和退出全屏。

恢复与长时间挂起使用受控时间模拟验证，没有执行真实的十小时等待或电脑休眠。浏览器兼容性实测为 Edge，其他现代浏览器使用同一套标准 Web API。
